# Optional desktop presets

MGO.ini contains reviewed MGO equipment values for the generic runtime. It is never loaded automatically. Missing equipment is reported and skipped by the editor.

To regenerate it after reviewing catalogue changes, build the editor and run:

```text
BowSpeedVREditor.exe --write-mgo-preset presets/MGO.ini
```

User settings are exported separately; do not edit this file to store personal tuning.
